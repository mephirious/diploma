## 🎯 Recommended Demo Flow

1. **Launch** → Show home page
2. **Language** → Switch EN → RU → KK
3. **Theme** → Toggle Light/Dark
4. **Browse** → Search "basketball"
5. **Details** → Open venue, swipe gallery
6. **Book** → Complete booking flow
7. **Reservations** → Show your booking
8. **Favorites** → Add to favorites

**Total demo time: 5-10 minutes**
